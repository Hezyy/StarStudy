# 星研维护路线图

0.4.0已在原版学习管理与0.3.0交互系统上增加独立账户、服务器数据归属、标准AI计划导入、账户同步与冲突保护、DeepSeek接口、短期BYOK、管理员与Linux部署工具。真实验证与配置边界见[本轮交付](PLATFORM_DELIVERY.md)。

接下来按实际价值推进：

1. 在专用Linux测试机完成Docker构建、PG17网络测试、容器重启、真实pg_dump/pg_restore、更新回退与HTTPS验收，成功后再向朋友开放。
2. 用真实iPhone Safari和Android Chrome验收PWA安装、文件选择/导出、后台挂起、更新、低存储与大图片恢复。
3. 配置限额较小的真实DeepSeek Key，验证连接、时延、Token账单估算与学习建议质量；模型结果始终经过业务校验和本人确认。
4. 改进逐条增量同步、冲突比较与手动合并、多年图片库的分页/压缩/配额监控，保留UUID与历史审计。
5. 增加邮箱验证与安全找回密码、会话设备管理、共享限流、多实例迁移锁和独立安全审计。
6. 增加计时校正审计、更多Excel表头映射、细化计划分片元数据与大计划性能测试。
7. 需要时再实现关闭应用后的Web Push、通知订阅、可撤销授权与加密BYOK持久化。

不为新功能清空数据库，不直接执行AI或导入文本，不把未运行的测试计为通过。
