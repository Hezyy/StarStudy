# 星研Excel导入

入口：个人设置 → 导入与备份。支持.xlsx、多工作表、首个非空行表头、字段映射、预览、日期/科目/时长/状态校验、重复检测、原始内容与结果报告。导入前不写数据库，确认后有效行和版本审计在同一事务写入，异常全部回滚。

## 一行一任务的普通表

必需字段是日期、科目、任务；可选网课、链接、章节、练习、预计时长、状态、备注。未知列可手工映射，未映射原文保存在任务rawImport。失败行保留在下载报告，离开页面前请下载修正。

日期支持Excel日期单元格、1900/1904序列、YYYY-MM-DD、斜杠和中文年月日；无效日期拒绝。分钟支持数字、分钟、小时及h，空值30分钟，范围1–1440。未知科目/状态不会猜造。状态导入不伪造StudySession。

限制：文件20MB、每表10000物理行/100列、全文件30000非空行。预览显示前200行，提交处理所有选中有效行。当前不是任意多行合并表头或嵌入图片提取器。

## 用户426天宽表

已实际读取原附件，16张表：说明、14张月份表、月度统计。日期2026-11-01至2027-12-31共426天。原件使用带命名空间前缀的有效XML，ExcelJS不能直接读取的情况由独立安全XML解析兼容层处理，不改原文件。

一行同时包含数学、408、英语/政治，导入器拆为独立科目任务。原课程字符串中的课程名称和章节按分隔符提取，阶段重点、星期、实际分钟、完成率、未识别字段等全部保留在rawImport。

整日总时长按可修改权重分配：数学50、408为35、英语10、政治5，按当日有内容的科目归一化，余数归最后一项，保证日总量完全相等。**这是逐科时长估算，原表没有逐科分钟值。**默认结果1462项，总54890分钟，重复0、错误0。课程来源、视频链接、集数、具体题号未核实的仍待补充；文本章节不会自动推断知识点依赖。

说明与月度汇总表默认不选。检查权重、日期、原文、科目和预览后点击确认。`imports/source-426.xlsx`是私人副本，被Git忽略，不在静态网站中；本机「载入已提供Excel」接口只在明确开启和回环访问条件下开放。其他设备使用文件选择器。

## 重复和失败保护

指纹为日期、科目ID、任务名、章节、练习（规范空白和大小写）；另保留原始sourceKey。因此编辑已导入任务后，原文件重复导入仍会跳过，软删除记录也参与防误恢复检测。跨表重复同样跳过。

同日同科同标题同章节同练习，即使时长不同，视为同一任务。确需重复学习，请用可区分的标题。修改源文件内容后按新指纹识别，不提供按Excel行号静默覆盖。

成功、失败、跳过数量都有结果反馈。写入使用批量事务，失败不破坏原数据。课程和题号不会通过导入器擅自联网补造。所有导入任务可在日历查看，列表每页50项用于保护手机性能。
