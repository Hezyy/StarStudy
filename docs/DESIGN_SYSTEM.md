# 星研交互设计规范

实现以src/app/experience.css为准；这是0.3.0统一体验层。

## 层次

页面标题说明当前位置；第一层展示当天最重要的信息；任务采用连续行，辅助指标和图表才使用独立表面。一个操作组只保留一个主要动作，常用次操作用secondary，低频动作用ghost。危险操作保留文本与确认。

## 动态

使用--motion-fast、--motion-base、--motion-sheet和--ease-out。路由入场由pathname变化触发；数据提交、Toast、秒表不能重新启动整页动画。任务勾选和进度变化保持节点与顺序，不把已完成行立刻搬走。所有非必要动画服从系统减少动态效果。

## 状态

异步：真实Promise或显式loading，不以定时器假装完成。错误：保留输入，给出可操作提示。完成：轻量反馈与可撤销状态。空数据：说明从哪里开始，不生成演示成绩。加载：使用稳定占位，不覆盖专注计时。

## 表单与浮层

新任务先填必要信息，其余用details展开。简单笔记行内编辑。桌面表单用侧抽屉，手机用底部抽屉；比较/恢复/计划确认保留完整差异。dialog负责焦点约束，关闭回到触发控件，Escape遵守未保存确认。操作处理中不允许关闭导致隐藏反馈。

## 可访问性

焦点可见，输入有标签，状态含文字，点击区域留足空间。手机输入16px，安全区和键盘用可视视口适配。保留原生选择器、日期输入、键盘和屏幕阅读器语义。图表保留固定空间和真实空状态，触屏采用点击Tooltip。

## 维护

不要向全局数据Context加入秒级状态；秒表使用局部useNow。不要把UI筛选写进学习记录，使用useViewState。不要绕过业务服务直接改完成率、计时或计划。新增组件复用Button、Modal和语义变量，避免每页另造动画/按钮规则。
