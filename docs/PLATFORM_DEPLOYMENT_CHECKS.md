## 已执行

| 检查                                      | 实际结果 | 边界                                                                                 |
| ----------------------------------------- | -------- | ------------------------------------------------------------------------------------ |
| Git Bash对全部`scripts/*.sh`执行`bash -n` | 通过     | 语法检查，非真实Linux安装                                                            |

| `npm run security:check`                  | 通过     | 已知密钥格式/私有目录扫描，不能替代人工与Git历史审查                                 |
| `bash scripts/test-deployment.sh`         | 通过     | 临时合成目录和mock Docker，未接触真实服务/数据库                                     |

控制流程测试实际检查：生成备份清单并校验，取消恢复不执行数据库写入，确认后带单事务/失败退出参数，损坏备份、遗漏数据库校验项和未校验附加文件被拒绝，空转储/转储失败不报成功，失败备份不改成功时间，Web目录备份被拒绝，恢复失败保持服务停止，更新迁移前停止旧应用写入且迁移失败不启动服务或删除卷，默认卸载不删除卷，未确认永久清除不删除卷。测试临时文件在项目忽略的backups下创建，结束后清理。

测试曾发现Windows Git Bash的sha256sum使用二进制标记` *`，原恢复清单验证只接受文本标记`  `；现已同时接受两种合法标记，并继续拒绝越界路径与符号链接，重跑通过。
