# 星研0.3.0体验升级

日期：2026-10-27，Asia/Shanghai。基于现有0.2.0改造；没有新增动画库、改变数据库版本或清空学习记录。DB仍为v3，完整备份仍为格式v2。

## 审查发现与实际改造

| 原问题                                        | 改造                                                                                                                      |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 全局Provider每秒更新now，全部消费页面随之重绘 | 删除全局秒级状态，useNow只订阅秒表；任务实际分钟和首页按更低频率更新                                                      |
| 首页大横幅和四个统计卡片抢走注意力            | 日期与今日进度作为第一层；数学优先分组，其余科目随后；周概况、错题和复盘放辅助区                                          |
| 每个任务像独立管理卡片，操作视觉权重相同      | 连贯任务行、安静的分科标题、清晰完成圆钮、独立开始/资料/编辑/展开操作                                                     |
| 完成任务缺少轻量纠错                          | 即时勾选和进度反馈，成功Toast提供撤销；撤销读取最新任务，后续修改有冲突保护                                               |
| 添加笔记还要开完整编辑弹窗                    | 详情内直接编辑、保存笔记；完整任务编辑继续保留                                                                            |
| 停止计时只出现提示，不知道下一步              | 非模态总结条显示本次时长，提供记下收获、标记完成及关闭                                                                    |
| 新建任务一开始展示全部字段                    | 保留名称/科目/日期/时长等基本字段，课程、练习、依赖收在更多选项；现有任务打开完整详情                                     |
| 表单没有即时日期预算上下文                    | 编辑日期/时长时显示保存后当日总量与超额；未保存提示与关闭/离开保护                                                        |
| 弹窗缩成手机小窗口，焦点行为不一致            | 桌面侧边抽屉、手机底部抽屉；大范围计划仍保留差异对话框；原生dialog管理焦点约束/Escape，记录触发控件以兼容Safari点击不聚焦 |
| 筛选和日期切换后丢失                          | 当前窗口sessionStorage保存今日、日历、资料、知识点、错题、统计、复盘周、设置页签等视图状态                                |
| 日历拖动缺少目标反馈                          | 拖动时突出目标日期；放下后仍先预览，取消不写入；保留可靠的批量改期替代入口                                                |
| 错题复习反复返回列表                          | 到期入口、题目与答案/解析在同一复习抽屉，支持保存并继续下一道                                                             |
| 图片选择后不知道发生了什么                    | 按真实文件读取数量展示进度、本地缩略预览和本机保存说明；不制造上传到服务器的假进度                                        |
| 周复盘密集表格和主观内容混排                  | 先展示客观记录，各科用简洁时长条；个人评价单独呈现，建议保留明确排期预览入口                                              |
| 空图表像有成绩一样展示坐标轴                  | 没有时长/知识点数据时展示解释与学习入口；不推算成绩。图表固定绘图区，触屏点击查看，鼠标悬停查看                           |
| 成功与错误提示打断节奏                        | 统一浮动Toast（手机顶部，避免遮挡学习按钮）、弹窗内错误、操作中加载与防重复；重要删除/恢复/计划应用仍需明确确认           |

## 统一设计系统

颜色、排版、间距、圆角、层次、按钮、表单、抽屉、菜单、状态及动画统一在src/app/experience.css。旧基础样式仍保留，由体验层统一覆盖；没有为每条路由独立创建互相冲突的主题。

| 项目           | 规范                                                                                 |
| -------------- | ------------------------------------------------------------------------------------ |
| 品牌           | 深蓝#233d61，星光金#b88b43只作小面积强调                                             |
| 正文/辅助      | #243047 / #65738a；深色模式独立语义变量                                              |
| 成功/错误/警告 | 语义色加文本或图标，任务状态不只依靠颜色                                             |
| 字体           | 系统中文字体栈，无外部字体网络请求；标题28–34px，正文14px，手机输入16px              |
| 间距           | 4/8/12/16/24/32/48px，按关系分组，不用等权卡片塞满页面                               |
| 圆角           | 8/12/18px；任务行保持连续阅读                                                        |
| 按钮           | 主操作深蓝，次操作柔和底色，低频操作透明；hover/active/focus/disabled/loading统一    |
| 反馈           | 按下轻微缩放，任务勾选/进度短过渡；页面入场只随路由变化，不随数据库刷新触发          |
| 动画           | 状态140–180ms，抽屉约220ms，退出160ms；主要使用opacity/transform                     |
| 减少动态效果   | CSS尊重prefers-reduced-motion，图表同步关闭动画，不延迟关闭操作                      |
| 布局           | 375px手机底栏，768px及以上侧栏；1150/1000px调整主体与辅助栏                          |
| 表单           | 16px手机输入避免Safari自动缩放；滚动区域与底部动作分离，按visualViewport适应键盘空间 |

按钮真实异步操作显示loading并拦截重复点击；关键提交还保留busy和业务事务保护。加载图标在按钮内部，不额外挤占一列。没有通过动画等待时间模拟成功。

## 保留的数据与业务规则

- 没有新增种子任务，也没有将截图数据或测试数据写入日常浏览器。
- 使用原saveTask、计时、导入、备份、排期及计划事务；状态快捷操作只是读最新记录后调用原服务。
- 结束计时后立刻标记完成时，读取数据库最新会话，避免订阅尚未更新造成误报；真正未结束计时仍拒绝完成。
- 完成撤销只改状态，保留计划、笔记、计时和审计；遇到后续编辑不会覆盖。
- 图片仍为IndexedDB Blob，不改为临时链接；备份、刷新、恢复和升级的原测试继续运行。
- 计划差异、删除、备份替换等重要操作没有取消确认。

## 验证与限制

最终命令与结果见[测试报告](TEST_REPORT.md)。截图使用隔离浏览器内创建的验收记录，不能当作用户真实学习成绩。

已检查桌面/手机/平板主要布局和操作；真实iPhone、真实输入法键盘、VoiceOver、系统边缘返回手势、后台挂起和长期帧率仍需设备验收，不能用Windows WebKit替代。原生拖动只在桌面测试，手机保留日期修改流程。

视图记忆只针对当前窗口，会随会话结束而丢失，不是云同步。未保存表单不会自动写入数据库；关闭和正常站内离开会提示，系统级后退/关闭行为仍应在真实设备验收。

数据变化仍使用原Dexie一致性快照订阅；秒级全站重绘已移除，但多年大量任务/图片的实体级订阅和性能基准仍可进一步优化。没有声称所有设备达到固定帧率。

## 使用新版

项目目录npm start，打开localhost:3000。已有PWA先保存正在编辑的内容，再使用“保存后更新”。没有强制刷新或清理IndexedDB。

手机依旧需要HTTPS才能正式安装和离线使用。可选云服务/AI的配置与未验证状态保持不变，见[配置说明](CONFIGURATION.md)。
