# 星研ChatGPT文件协作

入口「ChatGPT协作」。无需API或自动共享聊天上下文，使用明确文件传递。

## 导出

选择7/30天快捷范围，或手动开始/截止日期，填写调整要求。JSON和Markdown均包含目标、初试日期、科目及优先级、预算、近7/30天按日汇总、范围内任务、未完成内容、知识点状态和依赖、错题与复习数量。未来计划需单独勾选。

默认不含私人笔记、错题文本及图片；笔记和错题题目/原因可主动勾选，图片不放入协作报告。原始Excel字段和完整计划审计快照也不默认发给ChatGPT。完整备份与协作报告用途不同，备份包含全部私有学习数据。

同时下载「当前任务方案模板」，交给ChatGPT参考。该模板含当前真实UUID和basePlanVersion，避免模型编造ID。初始没有任务时模板使用新UUID、当前科目和占位标题，实际应用前自行填写真实任务内容。

## 导入契约

- app为`星研`，kind为`plan-adjustment`，schemaVersion为1。
- basePlanVersion必须匹配当前最新计划版本；过期文件要求重新导出。
- reason为调整原因；changes为1–5000项操作。
- update：已有taskId和plan（必需date、estimatedMinutes，可改标题、科目、章节、网课、练习、知识点、前置任务、截止日期和重要度）。
- create：从未使用的新UUID；plan还必须含title和subjectId。
- archive：已有taskId。已完成或产生过真实计时的任务不能由外部计划取消。

静态格式示例在`public/templates/plan-adjustment.example.json`，示例ID不可直接用于真实库。JSON Schema在`public/templates/plan-adjustment.schema.json`；页面均提供下载。动态当前模板更适合直接作为生成依据。

不接受额外的代码、指令或任意字段；不执行JSON中的内容。不能修改任务学习状态、笔记或计时记录。日期须在今天至初试日之间，单项预计1–1440分钟，新任务必须未完成。科目和知识点ID、任务依赖、重复记录、每日总预算及知识点前置顺序均需通过应用业务校验；仅通过JSON Schema不代表可以应用。

校验成功后只生成差异预览。确认、取消和修改方案均可用；预览后数据变化会拒绝旧方案。确认后任务、版本和必要设置在同一事务提交，失败回滚。

## 开发状态交接

页面可导出版本、已实现模块、已知问题、后续需求、最近更新、外部配置条件与用户填写的需求；交付文档和测试报告在`docs/`。不要假设ChatGPT和Codex自动共享当前数据库、仓库或聊天上下文。
