## 已复现并修复

- 全局每秒now导致所有消费页面更新：改局部时钟，增加主体DOM不更新断言。
- 关闭后焦点丢到页面或跳过导航：在输入自动聚焦之前保存触发位置；跟踪指针/键盘激活，兼容Safari点击不聚焦按钮。
- 抽屉入场位移短暂越界：浮层外框保持边界，采用轻量透明度过渡。
- 周复盘第一个字段被未保存标记的捕获阶段更新干扰：改为字段变更后的冒泡处理，保存/刷新回填重新通过。
- 结束计时后立刻完成误报：读最新数据库会话，再调用原事务服务。
- 同日任务随机插入导致列表移动：按创建时间与稳定ID排序；提交验收等待实际新行可见。
- 手机底部Toast遮挡任务按钮：改顶部提示，增加elementFromPoint实际命中断言。
- 异步按钮统一加载、互斥和错误反馈；重要提交还保留原事务和busy校验。
