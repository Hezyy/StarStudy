# 星研已知限制

版本0.4.0，2026-10-28。实际验证见[本轮交付报告](PLATFORM_DELIVERY.md)，0.3.0测试报告作为历史记录保留。

1. 平台模式需要配置真实PostgreSQL、会话密钥和HTTPS。当前设备没有Docker、原生PostgreSQL或生产域名；嵌入式PG引擎测试、静态Compose和mock脚本测试不能代表实际部署通过。
2. 未在真实iPhone/Android上验收安装、系统文件选择、后台挂起或低存储回收。Windows WebKit使用每例独立持久化测试目录以覆盖Blob保存，不能代替真实Safari。
3. 同步使用按账户隔离的全量快照和版本检查，冲突时保留本机并由用户选择，不做逐条自动合并。大量图片会增加传输与备份成本，尚无多年海量图片压力测试。
4. 本机缓存并非磁盘加密。退出账户保留本账户缓存，以便再次登录；永久删除账户会在确认后清除此账户在当前浏览器的缓存，旧版个人数据库保留。共享设备应使用独立浏览器用户或清理相应站点数据。
5. 计时依赖设备时钟，关闭页面不会自动停止。相同计时的服务器状态可收敛，本机和服务器都改动时必须解决冲突；尚无手工计时校正审计页面。
6. 默认邀请注册、密码哈希、权限与所有权、CSRF和限流已有测试；未做第三方渗透测试、完整安全审计、邮箱验证、邮件找回密码或多实例共享限流。
7. DeepSeek和可选OpenAI只完成隔离假传输/额度/错误协议测试，未调用真实付费服务。BYOK仅服务端内存15分钟，不支持持久化加密密钥库。
8. Excel宽表逐科时长按可编辑权重估算，课程集数与题号待核实；不保证识别任意多行表头、嵌入图片或自然语言。Markdown自由文本需要配置AI转换，不能直接执行。
9. 普通同步不会删除真实计时或已完成任务；明确确认的账户恢复会替换该账户数据。账户JSON恢复上限38MB，本地恢复100MB；更大数据库应使用部署备份，恢复前务必先在独立服务器演练。
10. 提醒只在应用打开且已获权限时工作。关闭应用后的Web Push、持续后台同步、逐条冲突合并、OAuth登录尚未实现。
11. 旧任务缺少实际完成日期时，不能精确还原历史完成和积压曲线；不会编造缺失学习时间或掌握程度。
12. 当前类型检查与ESLint均通过，ESLint为0错误0警告；这些检查及功能回归不等同于性能或生产负载验收。

本地模式仍无需账户和付费AI；所有新用户默认目标均可自行填写，不包含原用户的私人院校和专业。实际招生科目由本人核实。
