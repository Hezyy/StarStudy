# 星研完整备份和恢复

数据只属于当前浏览器的当前站点来源。清理浏览器、设备故障、端口或域名改变都会影响本地数据可见性，请定期把备份保存到浏览器之外。

0.4.0账户模式另有服务器副本：下载完整备份读取本账户的本机缓存；账户页的服务器导出则读取已同步服务器副本。账户恢复需要联网，通过服务端预览与明确确认后替换本账户服务器数据，其他用户不受影响；本机和服务器均保留恢复前快照。普通自动同步不能删除或改写真实计时，只有确认的恢复路径可以替换。账户恢复文件上限38MB；原版本地恢复仍为100MB。大图片库应使用部署级PostgreSQL备份，参见[部署说明](DEPLOYMENT.md)。

## 备份

入口：个人设置 → 导入与备份 → 下载完整备份。

当前JSON格式v2、数据库v3，仍接受旧格式v1/数据库v2文件。包含13张核心表：个人资料、考试目标、科目、知识点与状态历史、资源与任务关联、任务、计时、错题及图片、复习、周复盘快照、计划版本和设置。

图片在IndexedDB中为Blob，JSON使用MIME+Base64，可往返恢复。运行中的计时在导出文件中冻结为暂停状态，封闭当前片段；当前设备原计时不因导出而停止，避免恢复后把迁移等待时间算入学习。

备份是明文，可能包含私人笔记和图片，请存到可信位置。协作中心的精简报告不能代替完整备份。云认证会话和AI网关口令不放进星研核心备份。

## 恢复

1. 结束当前计时，包括暂停中的计时。
2. 选择JSON，最大100MB，校验格式、版本、UUID、日期、枚举、时长、URL、计时顺序、知识点循环和核心关联。
3. 查看每表当前、备份和同ID冲突数量。恢复是整库替换，不是合并；备份里没有的当前记录也会替换掉。
4. 勾选确认并执行。若预览后本地又有新数据，要求重新预览，避免覆盖未看到的变化。
5. 在事务前准备当前完整快照；事务内再次检查并发变化，保存恢复前JSON，再替换核心表并核对数量。任何写入失败整批回滚。

恢复前快照保存在独立recoverySnapshots表，不递归包含在后续备份中。通过「下载恢复前快照」取得最近一次文件，再用相同入口恢复。该快照仍在同一浏览器中，不能代替外部下载备份。

科目切换、归档、排期和安全撤销不会删除真实计时与图片。版本撤销只恢复计划字段；完整备份恢复则按用户明确确认替换整个学习空间，操作目的不同。

## 跨设备

没有配置云服务时，电脑导出、手机恢复即可迁移，但不会自动合并两台设备同时产生的进度。恢复前分别保留两边备份。配置后的可选云快照同样提供版本冲突检查、预览和恢复前备份，真实云服务联调条件见CONFIGURATION.md。
