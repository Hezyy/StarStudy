# StarStudy Plan Schema v1.0.0

这是「新学习计划」协议，独立于已有`plan-adjustment`任务调整协议。已有真实任务ID的调整仍从ChatGPT协作中心导入，不能把两者格式混用。

## 操作流程

进入`/plan/import-ai/`，填写本人目标、预计日期、基础、科目、时间预算和本次范围，生成提示词。可以复制到ChatGPT、DeepSeek或其他工具，也可下载提示词。不要让AI把不确定招生信息当官方结论，未核实课程/集数/题号留空或待核实。

取得结果后粘贴JSON或选择文件，选择导入方式，校验并阅读预览。只有点击确认才写入，取消不修改学习数据。平台模式由服务端生成内部UUID和预览记录，确认时再次检查账户与数据版本；本地模式仍使用本地独立事务和恢复安全快照。

## 字段约定

| 字段                | 说明                                                                                         |
| ------------------- | -------------------------------------------------------------------------------------------- |
| schemaVersion       | 必须为字符串`1.0.0`，未知版本不自动猜测                                                      |
| planId              | 稳定计划代号，后续月份保持一致                                                               |
| planName            | 计划名称                                                                                     |
| generatedAt         | UTC ISO时间戳（Z结尾），例如2026-10-28T00:00:00.000Z                                              |
| startDate / endDate | YYYY-MM-DD；允许按月分片，计划范围不可倒置                                                   |
| timezone            | 当前固定Asia/Shanghai                                                                        |
| examTarget          | 本人院校、专业、YYYY-MM-DD初试日期                                                           |
| subjects            | externalId、名称、category及priority                                                         |
| resources           | externalId、subjectId、标题、URL、老师、课程、章节和选集说明                                 |
| knowledgePoints     | externalId、subjectId、名称、章节、dependencyIds                                             |
| tasks               | 稳定externalId、日期、subjectId、标题、说明、分钟、类型、优先级、知识点/资源引用、练习、备注 |
| metadata            | source、可选chunk、notes，仅作数据，不执行其中的指令                                         |

外部标识使用字母、数字、下划线、横线和点，最长100字符。引用指向同一文件定义的externalId，不使用数据库UUID冒充外部引用。任务类型为course、exercise、review、exam、reading、other；科目类别为math、english、cs、politics、custom；priority为1—10的整数，数字小优先。时长单位分钟，任务限制1—720分钟，不使用小时文本或负数。

字段采用严格校验，未知字段不会被当作数据库字段直接写入。资源仅允许安全http/https地址；AI提供的链接不会被自动标为已核实。打卡和导入不自动判断知识点已经掌握。

## 解析与错误

支持纯JSON、单个JSON的Markdown代码块（允许区块前后说明，多个JSON区块需分开）、JSON文件。CSV/Markdown表格必须具有明确表头，可用日期/date、科目/subject、任务/任务名称/title、时长/时长（分钟）/分钟/estimatedMinutes等列名。科目需已在本人配置中存在，表格原始行内容保存在备注，无法识别时会提示，不根据散文猜测日期。

Excel入口复用原有多工作表与字段映射流程。Markdown中若包含JSON代码块，应选择JSON格式；只有表格选择Markdown表格。复杂自然语言只有配置AI后才转换，转换结果仍回到同一校验流程，不保证任意文本100%识别。

校验覆盖JSON语法/版本/字段、真实日期、时长、外部ID重复、科目/资源/知识点引用、循环依赖和显著先后关系、预算、考试范围、已有任务重复。预览展示新增、重复跳过、范围取消、保留项、预算问题和无任务日期。存在阻止性问题时不能确认，需要修改或分拆计划。

## 三种模式

- 新建：保留已有任务；已有相同planId时要求改用合并。
- 合并：新增后续月份；相同计划+稳定任务引用或相同任务指纹会去重，不覆盖历史。
- 替换范围：只取消范围内可安全替换的未完成任务，保留完成任务与带真实学习记录的任务。取消为计划字段变化，保留版本与恢复路径。

如果想修改已导入任务而非追加，应通过任务编辑、动态排期或已有任务调整协议进行明确预览，不能仅换同一externalId的内容并期待覆盖。

## 300—500天长期计划

建议每次生成一个月：相同planId、稳定subject/resource/knowledgePoint标识、每个文件包含被引用的定义；任务externalId按实际日期和序号稳定命名。后续月份用合并模式。不要依赖AI一次输出超长JSON，输出被截断必须重新生成，不能把部分内容强行导入。

当前单个协议范围最多550天、最多20000项任务，文本上限12MB。空白日期会显示为计划缺口，可能是休息，也可能漏排，需要本人核对；系统不虚假补齐。改变初试目标应在个人设置明确修改，不会凭文件静默改个人目标。

## 隐私与兼容

提示词只含当前填写目标与基础，不默认导出全部私人笔记或图片。使用内置AI时发送前核对文本。导入内容是待校验数据，不执行任何代码或自然语言指令。

未来协议变更应明确版本与迁移规则；v1.0.0不默认接受未知版本。原有JSON完整备份和已有任务调整文件各有自己的版本，不是同一协议。
