# 星研 MVP 测试报告

日期：2026-10-27（Asia/Shanghai） · 版本：0.1.0。

## 实际环境

Windows / PowerShell，Node.js 26.7.0，npm 11.19.0。锁定依赖包括 Next.js 16.4.3、React 19.3.1、Dexie 4.4.7、ExcelJS 4.4.0、Vitest 4.1.12、Playwright 1.64.1。浏览器由 Playwright 下载：Chrome for Testing / Chromium 156、WebKit 27.2。

测试对象为 `npm run build` 生成的静态生产应用，由 `scripts/serve.mjs` 在 localhost:3000 提供服务；离线测试使用真实生产 Service Worker 和浏览器 IndexedDB，不用假接口替换任务持久化。

## 单元测试覆盖

- 首次初始化不生成伪造记录；数据库关闭 / 重开保留任务。
- 时间戳片段的暂停、重复暂停、恢复、重复恢复和结束准确累计；并发开启计时只成功一条。
- 运行中的任务不能直接完成；完成任务禁止改期 / 删除；软删除保留历史计时。
- 手动改期保存前后快照；拆分保持总预计时长；跨午夜实际时长归属与连续打卡。
- 特殊日期预算和考试周降时覆盖默认预算。
- Excel 日期格式、多表、状态、科目、列映射、原始未知列、重复导入及编辑后重复导入保护。
- 真实 XLSX 读写和损坏文件拒绝；模拟事务写入失败时整批导入回滚。
- 完整备份及图片 Blob 字节往返；恢复预览冲突数、恢复前快照、版本 / ID / 日期 / 悬空关联拒绝。
- 备份冻结运行计时；恢复保护未结束计时；模拟存储异常回滚；编码图片期间出现并发新记录时停止恢复。
- 科目 / 初试日期 / 预算修改保留历史任务，重新启用旧科目；无效设置拒绝写入。
- 真正建立 v1 数据库再升级到 v2，保留任务并补齐关联数组。

错题图片单元测试验证的是存储与备份字节往返，**不是尚未实现的错题 UI 图片上传 / 刷新验收**。

## 真实 iPhone 手动验收步骤

1. 将 `out/` 部署到 HTTPS；用 Safari 打开，确认图标、中文名称「星研」、安全区和底部导航。分享 → 添加到主屏幕，重新从主屏幕打开。
2. 新建任务、填写章节 / 笔记，等待成功提示后刷新；退出并重新打开 Safari 或 PWA，确认记录保留。
3. 开始计时约 30 秒 → 暂停约 10 秒 → 恢复约 20 秒，确认暂停期间秒表不增长，随后结束并备份，检查片段合计约 50 秒。分别测试锁屏、切换应用和刷新场景。
4. 首次联网等待缓存完成，再开启飞行模式，重开或刷新星研；确认离线提示、今日和日历可打开。
5. 离线新建任务、标记部分完成、完成与记笔记，等待反馈后重开；恢复网络后确认记录仍在。
6. 从电脑下载备份传到 iPhone，在恢复预览核对各表数量，明确确认替换；回传一份手机备份，检查图片与关联数据（错题 UI 上线后补充图片实际操作）。
7. 发布新生产版本并重新联网；在未保存的编辑状态下确认不会自动刷新。保存后点击更新，确认新界面加载且数据仍在。
8. 测试删除取消、预算超额、未知列 Excel、错误 JSON 和恢复前快照下载；任何失败都记录设备型号、iOS 版本和复现步骤。
