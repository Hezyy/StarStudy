## 复现与修复

1. 原件有效XML带命名空间前缀，ExcelJS直接读取失败：新增安全XML兼容解析，原件16表实际解析和完整导入通过。
2. 1462项同步逐条写入及列表渲染影响性能：改批量事务、列表50项和差异100项分页。WebKit原件导入为较慢路径，断言等待真实完成，未通过缩减数据绕过。
3. 移期后手动拆分复制plannedMinutes，导致预算双计：拆分后两段分别保存分配量，单元和四组浏览器复测总量40分钟通过。
4. 原生dialog会遮住弹窗外的错误反馈：错误也在弹窗内部显示。
5. Windows WebKit临时上下文的原生Blob写入抛UnknownError，独立原生IndexedDB最小用例同样失败；持久化上下文成功。测试夹具改为每例独立持久化目录，仍真实写Blob。四组图片刷新和JSON恢复显示均通过。这不是绕过图片验收，也不表示真实iPhone已通过。
6. 最终复核中WebKit快速切页偶发后台RSC预取访问控制错误：站内AppLink关闭重复预取，保留客户端导航，离线资源仍由Service Worker预缓存。原失败用例连续3次复测通过，并新增断言确认无后台预取请求，未屏蔽页面错误。行为依据[Next.js官方Link文档](https://nextjs.org/docs/app/api-reference/components/link#prefetch)。
7. 首页周概况还使用原预计总量，可能把已调整或未排期内容再次计入预算：统一使用当日分配量函数，与完整统计页一致；新增测试验证100分钟任务当日分配30分钟、60分钟余量未排期时，两处都只计30分钟。

## 真实iPhone手动验收

1. 部署out/到HTTPS，Safari打开，检查星研名称/图标、安全区和底栏；分享→添加到主屏幕，从图标重开。
2. 新建任务、填章节/笔记，成功后刷新，关闭并重开Safari/PWA确认保留。
3. 新建错题上传相册图片，填写答案/解析/知识点；保存刷新再打开，记录复习后检查历史与下次日期。
4. 下载完整备份；预览恢复确认后重开图片，检查任务、计时、知识点、复盘、版本和关联数量；下载恢复前快照。
5. 计时30秒→暂停10秒→恢复20秒→结束，检查约50秒。分别测试锁屏、切换和刷新，结束前不把等待时间误认成暂停。
6. 首次联网等待缓存，再飞行模式重开/刷新；新建任务、记笔记和打卡，重开及恢复网络后检查完整。
7. 给数学未掌握知识点建立依赖，设置考试周30分钟；生成预览核对每日日量、缺口和后续任务。取消不变，确认后再预览撤销，核对真实记录仍保留。
8. 从电脑迁移备份，确认替换前两端均保存外部备份；本地数据库不自动跨设备合并。
9. 发布新版本，编辑时观察没有强刷；保存后主动更新，确认数据仍在。测试通知授权/撤销和应用打开时提醒。
10. 检查375px弹窗键盘/按钮/滚动及深色模式；记录设备型号、iOS版本和复现步骤。可选云服务另按CONFIGURATION.md执行两账户隔离/两设备冲突验收。
