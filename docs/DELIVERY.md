- Recharts日/周/月时长、科目分布、完成率、计划差异、掌握度、错题复习、积压、连续学习、7/30天报告。

- ChatGPT Markdown/JSON隐私范围报告、稳定ID动态模板、示例与Schema；外部方案校验版本/ID/日期/预算/重复/依赖/完成保护，再预览确认。
- 原始Excel多表、带命名空间XML、每日多科宽表、字段映射、去重与原始内容；备份包括全部核心数据、图片与版本，支持旧格式、预览、恢复前快照、失败回滚。
- DB v1/v2无损升级v3；生产PWA、响应式导航、离线写入、更新提示、存储持久化申请。

## 启动与使用

已安装依赖并生成out/：执行npm start，打开http://localhost:3000。修改后先npm run build，新机器先npm ci。

iPhone先部署HTTPS，Safari打开→分享→添加到主屏幕，联网缓存后离线验收；电脑Chrome可用安装入口。重要数据定期完整备份。下一步见[路线图](ROADMAP.md)。
